# SpriteForge 2D 游戏素材生成器

七牛云 × XEngineer 暑期实训营第一批次题目二作品：用户通过输入文本和简单参数，高效生成可用于 2D 游戏流程的素材。

## 项目亮点

- 文本描述驱动：输入角色、道具、地块、技能图标等需求后生成对应素材。
- 参数化控制：支持素材类型、风格、画布尺寸、动画帧数、细节、风格一致性和调色板。
- 游戏开发友好：可导出透明 PNG、Spritesheet 和 JSON 元数据，适配 Unity、Godot 等常见 2D 工作流。
- 成本可控：当前版本采用前端本地程序化生成，无需后端推理成本，适合作为低成本原型和批量草稿工具。
- 风格一致：同一 seed、调色板和参数下可复现素材，方便团队维护统一视觉风格。
- 项目风格包：一键生成主角、敌人、掉落物、Tile 地块和技能图标，用一组资产展示同主题视觉一致性。

## 快速运行

直接用浏览器打开 `index.html` 即可运行。

也可以使用任意静态服务器：

```bash
python -m http.server 5173
```

访问 `http://localhost:5173`。

## 使用方式

1. 输入素材描述，例如“赛博武士，蓝色能量刀，适合横版动作游戏”。
2. 选择素材类型、风格、尺寸和动画帧数。
3. 调整调色板、细节和风格一致性。
4. 点击“生成素材”刷新 seed 并生成新结果。
5. 点击“生成同风格资产包”，查看一组可配套使用的 2D 游戏资产。
6. 导出 PNG、Spritesheet 或 JSON 元数据，导入 Unity/Godot 继续制作。

## 技术方案

本项目使用原生 HTML、CSS、JavaScript 和 Canvas 实现：

- Canvas 绘制透明背景素材与序列帧。
- Seeded random 保证结果可复现。
- 按素材类型实现不同生成策略：角色、道具、Tile 地块、技能图标。
- 通过同一 seed、prompt、风格和调色板生成项目风格包，降低多资产之间的视觉割裂。
- 使用浏览器 Blob/DataURL 完成本地导出。
