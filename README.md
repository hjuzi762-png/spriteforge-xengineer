# SpriteForge

这是我为 XEngineer 暑期实训营题目二做的一个 2D 游戏素材生成小工具。它不是完整的图像生成系统，更偏向一个可以本地运行的原型工具：输入描述，调几个参数，然后生成像素风角色、道具、地块和技能图标。

我做这个方向主要是想解决游戏原型阶段的一个小问题：很多时候并不需要马上得到最终美术，只需要先有一批风格接近、尺寸统一、能放进 Unity 或 Godot 里试玩法的素材。

## 现在能做什么

- 根据文字描述和素材类型生成角色、道具、Tile 地块、技能图标。
- 支持 64、96、128 像素尺寸，以及 1 到 8 帧动画。
- 可以调整风格、细节、调色板和 seed。
- 能导出单张 PNG、Spritesheet 和一份 JSON 描述文件。
- 对一些常见关键词做了处理，比如暗黑、紫色、火焰、冰、雷电、机械、法师、弓箭、宝箱、骑士等。
- 默认风格改为“曲线精绘”，使用椭圆、贝塞尔曲线、渐变、软阴影和描边生成素材；像素风作为可选模式保留。
- 新增无依赖 Node 后端 `server.js`，提供 `/api/semantic-parse` 语义解析接口，前端生成时会优先调用后端识别小狗、猫头鹰、特斯拉、车辆、飞船、建筑、药水、武器等描述，接口不可用时自动回退到本地规则。
- 像素模式也改为 48 格精细模板，默认使用 256 像素高清画布，补充轮廓、五官、翅膀、装备、高光和粒子细节，避免早期 32 格低模过于粗糙。
- 页面底部有一组“项目风格包”，用同一套参数生成主角、敌人、掉落物、地块和技能图标，方便看整体风格是否统一。
- 支持上传 PNG、JPG、WebP 图片，再输入“奔跑、跳跃、挥砍、漂浮、旋转、变大、缩小、雷电拖尾”等描述，把图片转换为 1 到 8 帧的动作化素材。
- 上传图片会先做主体识别与自动裁切，默认切到 512 像素超清画布，避免整张照片被缩成一小块。
- 支持本地注册和登录，包含用户名规则、密码强度、确认密码、算术验证码和失败次数锁定；导出的 JSON 会记录作者信息，登录用户最近生成记录会保存在浏览器本地。

## 快速运行

推荐使用内置 Node 后端运行，这样可以启用语义解析接口：

```bash
node server.js
```

访问 `http://localhost:5173`。

也可以直接用浏览器打开 `index.html`，但此时会退回纯前端规则解析。

也可以使用任意静态服务器：

```bash
python -m http.server 5173
```

访问 `http://localhost:5173`。

## 使用方式

1. 输入素材描述，例如“暗黑骑士，紫色火焰剑，适合横版动作游戏”。
2. 选择素材类型、风格、尺寸和动画帧数。
3. 调整调色板和细节参数。
4. 点击“生成素材”。
5. 如果想看一整组资产，可以点击“生成同风格资产包”。
6. 如果已有参考图，可以在“上传图片动作化”中选择图片，填写动作或变化描述，再点击“应用到上传图”。
7. 需要放进游戏工程时，导出 PNG、Spritesheet 或 JSON。

## 技术方案

项目没有使用框架，主要是原生 HTML、CSS、JavaScript 和 Canvas。

- Canvas 负责绘制透明背景素材和序列帧。
- seeded random 用来保证同样的输入可以复现。
- 不同素材类型有不同的绘制逻辑：默认走曲线矢量化绘制，像素风走更高密度的精细模板。
- 后端当前是轻量语义解析层，不调用外部模型；如果后续接入真实图像生成模型，可以把 `/api/semantic-parse` 扩展为模型代理或增加 `/api/generate-image`。
- 上传图片动作化使用 Canvas 对原图做平移、缩放、旋转、残影、元素粒子和攻击弧线等帧变化，适合快速产出占位动画。
- 上传图片默认不再跟随像素风降采样，只有用户在描述里写“像素”时才会主动像素化；预览 Canvas 也区分高清图和平滑/像素图，减少浏览器缩放造成的虚化。
- 登录注册使用浏览器 localStorage 保存演示账号、登录状态和最近生成记录，不依赖后端服务，并加入基础前端校验。
- 没有专门模板的描述，会尽量用颜色、形体、装备和元素特效组合出一个接近的结果。
- 导出使用浏览器自带的 Blob 和 DataURL。

## 目前的不足

- 现在还是程序化生成和图像帧变换，不是真正的任意文本生成图片或视频。
- 没有专门规则的描述，效果只能做到大致接近，不能保证完全符合想象。
- 复杂角色的动作还比较简单，后面可以继续补行走、攻击、受击等动画。
- 工程格式目前只做了通用 JSON，Unity/Godot 的专用导入文件还可以继续完善。
- 登录注册是前端原型实现，只用于作品演示和本地记录，不应当作为真实生产账号系统使用。

## 后续想法

- 增加更多常见素材模板，比如武器、药水、建筑、怪物。
- 增加批量生成和历史记录。
- 支持导出 TexturePacker JSON、Godot SpriteFrames 等格式。
- 如果接入图像生成模型，可以让模型负责复杂造型，本工具负责尺寸、切帧、调色和导出。
