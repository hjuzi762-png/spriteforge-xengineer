# 参赛提交说明

## 作品名称

SpriteForge 2D 游戏素材生成器

## 选择题目

题目二：2D 游戏素材生成

## 一句话介绍

SpriteForge 是一个面向独立游戏开发者和美术原型阶段的 2D 素材生成工作台，支持用文本描述和参数快速生成角色、道具、Tile 地块、技能图标，并导出到 Unity/Godot 工作流。

## 核心能力

- 输入文本描述，生成对应 2D 素材。
- 支持像素风、手绘厚涂、霓虹科幻、水墨剪影四种视觉方向。
- 支持 64、96、128 像素尺寸和 1 到 8 帧动画。
- 可自定义调色板，保持同一项目视觉一致性。
- 支持 PNG、Spritesheet、JSON 元数据导出。
- 全部在浏览器本地运行，减少推理和服务端成本。
- 支持“项目风格包”，一键展示主角、敌人、掉落物、Tile 地块和技能图标的统一视觉效果。

## 展示建议

演示时可按以下路径操作：

1. 打开 `index.html`。
2. 输入“赛博武士，蓝色能量刀，适合横版动作游戏”。
3. 选择“角色 / 霓虹科幻 / 64 x 64 / 4 帧”。
4. 点击“生成素材”，展示自动播放的动画预览。
5. 点击 `Spritesheet` 和 `JSON`，说明可导入 Unity/Godot。
6. 点击“生成同风格资产包”，展示同一主题下多类资产的风格一致性。
7. 切换到“Tile 地块”或“技能图标”，展示同一工具覆盖多类 2D 资产。

## 与题目要求的对应关系

- 高效：参数化生成，浏览器即时反馈。
- 低成本：本地 Canvas 程序化生成，无后端推理成本。
- 素材质量：支持调色、风格、尺寸和动画帧，适合作为游戏原型资产。
- 风格一致性：seed、调色板和风格参数可复现，并可通过项目风格包直观看到多资产统一效果。
- 融入流程：导出透明 PNG、Spritesheet 和 JSON，适配 Unity/Godot。
