# 提交说明

## 作品名称

SpriteForge

## 选择题目

题目二：2D 游戏素材生成

## 简介

SpriteForge 是一个在浏览器本地运行的 2D 游戏素材生成工具。它可以根据文字描述和参数生成一些原型阶段可用的像素素材，比如角色、道具、地块和技能图标。

## 已实现功能

- 输入文本描述并生成素材预览。
- 支持曲线精绘、像素风、手绘厚涂、霓虹科幻、水墨剪影五种风格。
- 对暗黑、紫色、火焰、冰、雷电、机械、法师、弓箭、猫头鹰、章鱼、骑士、宝箱等关键词做了简单解析。
- 支持 64、96、128、256、512 像素尺寸和 1 到 8 帧动画，默认使用 256 像素高清画布。
- 默认生成管线改为曲线精绘，使用椭圆、贝塞尔曲线、渐变、软阴影和描边绘制，减少素材全是直线和方块的问题。
- 像素模式从早期 32 格低模升级为 48 格精细模板，补充轮廓、五官、装备、高光、翅膀和粒子细节。
- 新增无依赖 Node 后端，提供 `/api/semantic-parse` 语义解析接口，用于识别小狗、猫头鹰、特斯拉、车辆、飞船、建筑、药水、武器等描述；接口不可用时前端自动回退到本地规则。
- 新增 `/api/generate-image` OpenAI Images API 后端代理，配置 `OPENAI_API_KEY` 后可调用真实图像生成模型，并把返回图片接入预览、Spritesheet、PNG 与 JSON 导出流程。
- 支持 `OPENAI_BASE_URL` 配置，便于在网络受限环境下使用兼容 OpenAI Images API 的代理或中转服务。
- 支持自定义调色板。
- 支持 PNG、Spritesheet、JSON 导出。
- 支持生成一组同风格资产，包括主角、敌人、掉落物、Tile 地块和技能图标。
- 支持用户上传 PNG、JPG、WebP 图片，并根据动作描述生成对应帧变化，例如奔跑、跳跃、攻击、旋转、漂浮、缩放、发光拖尾和元素粒子。
- 上传图片默认走主体识别和高清保真流程，自动裁掉大面积背景并切换到 512 像素画布；只有描述中明确写“像素”时才主动像素化。
- 支持本地注册、登录和生成历史记录，包含用户名规则、密码强度、确认密码、算术验证码和失败次数锁定，导出 JSON 会带上作者、素材来源和上传图动作描述。

## 演示步骤

1. 运行 `node server.js`，打开 `http://localhost:5173`。如需真实 AI 图片生成，先配置 `OPENAI_API_KEY`。
2. 输入“暗黑骑士，紫色火焰剑，适合横版动作游戏”。
3. 选择“角色 / 像素风 / 64 x 64 / 4 帧”。
4. 点击“生成素材”，查看动画预览。
5. 点击 `Spritesheet` 和 `JSON`，查看导出结果。
6. 点击“生成同风格资产包”，查看同一主题下的多类资产。
7. 再切换到“道具”并输入“冰晶宝箱，蓝白高光，可作为掉落物”，查看宝箱素材。
8. 注册或登录一个本地账号，上传一张图片，输入“高清保真，向右奔跑并挥砍，带蓝色雷电拖尾”，点击“应用到上传图”，查看图片被转换成高清动作帧。

## 和题目要求的对应

- 生成效率：本地 Canvas 生成点击后马上能看到结果；AI 模型生成会根据网络和模型响应时间返回。
- 成本：默认本地规则生成零推理成本；真实图像生成通过可选 OpenAI Images API 接入，按 API 使用产生外部模型成本。
- 素材质量：支持尺寸、动画帧、风格和调色，适合做游戏原型；配置真实图像模型后，可用于更复杂描述的素材生成。
- 风格一致性：同一 prompt、seed、调色板和风格参数下，可以生成一组比较统一的资产。
- 接入流程：导出透明 PNG、Spritesheet 和 JSON，后续可以导入 Unity 或 Godot。
- 用户自定义：可以把已有角色图、道具图或草稿图上传后做动作化处理，降低从参考图到可测试动画的成本。

## 目前限制

未配置 `OPENAI_API_KEY` 时，项目主要依赖程序化生成、关键词组合和 Canvas 图像帧变换；配置后可通过后端代理调用真实图像生成模型。登录注册是前端本地演示能力，不用于真实生产鉴权。对于模型不可用或本地规则没有覆盖到的复杂描述，只能生成接近的草稿效果。

## 原创性说明

当前版本没有引用、fork 或复制第三方项目代码。代码围绕题目独立实现，只使用浏览器标准 API。
