# Demo 录制脚本

这个文件用于录制作品 demo 视频时参考，视频控制在 1 到 2 分钟即可。

## 录制顺序

1. 打开 `index.html`，简单介绍这是一个浏览器本地运行的 2D 游戏素材生成工具。
2. 输入：

```text
暗黑骑士，紫色火焰剑，适合横版动作游戏
```

3. 选择“角色 / 像素风 / 64 x 64 / 4 帧”，点击“生成素材”，展示动画预览和 Spritesheet。
4. 切换到“道具”，输入：

```text
冰晶宝箱，蓝白高光，可作为掉落物
```

5. 点击“生成素材”，展示宝箱结果。
6. 点击“生成同风格资产包”，展示主角、敌人、掉落物、Tile 地块和技能图标。
7. 注册一个本地账号或登录已有账号，说明导出文件会记录作者信息。
8. 在“上传图片动作化”中上传一张图片，输入：

```text
向右奔跑并挥砍，带蓝色雷电拖尾
```

9. 点击“应用到上传图”，展示上传图被转换为动作帧，并说明同样可以导出 Spritesheet。
10. 点击 `PNG`、`Spritesheet`、`JSON`，说明这些文件可以继续放进 Unity 或 Godot 项目中使用。

## 讲解重点

- 工具不依赖后端服务，直接在浏览器本地生成。
- 同一组 prompt、seed、调色板和风格参数可以复现结果。
- 项目风格包用于检查一组资产是否看起来属于同一个游戏。
- 上传图片动作化适合把已有草图、头像或道具图快速转成游戏原型可用的动作素材。
- 登录注册是本地演示功能，用于展示用户作品归属和最近生成记录。
- 当前版本主要面向原型阶段，复杂素材后续可以继续扩展模板或接入图像生成模型。
